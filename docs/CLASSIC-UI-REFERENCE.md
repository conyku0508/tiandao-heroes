## 採用的介面
上方細選單、橫向資源／日期／倍速列；中央地圖；藍色標題灰色浮窗；底部多行事件；右下可收合小地圖。小地圖從目前地形、建築、人物與鏡頭生成，可點擊定位，不是裝飾圖。保留暫停/1/2/4與既有派工玩法，不照參考圖改成3倍或Lv5。

手機將倍速併到最上排，資源另用窄列，主要按鈕保留觸控範圍；直向仍提示旋轉。只加入已實作功能的選單，不放無效的軍事／外交按鈕。

## 地形v3
取消大型矩形高台，改成低起伏山麓；主要建築各有2×2平坦地基。自然地表使用共享角點的連續面，保留16px邏輯階高與尋路限制。材質以原始像素密度重複，避免拉伸斜坡造成透明裂縫或放大馬賽克。不使用整段大型直立崖牆擋住村落。
新局mapVersion=3；舊v1/v2存檔保持自己的地形。開始新局不會自動覆蓋舊存檔，只有明確存檔才寫入。

## 驗證與限制
型別、單元測試、建置；瀏覽器檢查浮窗、建造、多人派工、存讀檔、小地圖移動／收合、667×375、844×390、1024×768及直向提示。測試入口的canvas參數僅DEV啟用，用於驗證Canvas相容；正式版本Phaser.AUTO。目標30fps，模擬仍採固定tick，不依賴渲染幀率。

美術仍是原創候選，房舍密度、材質過渡、人物造型與動畫尚未達到使用者提供參考圖的完整品質。未加入新經濟或戰鬥系統。

最終驗證：14項測試與建置通過；WebGL介面檢查及Canvas完整流程檢查通過，未偵測到JS錯誤。仍有Phaser主bundle超過500KB的建置提示。真機瀏覽器驗收待使用者試玩。
