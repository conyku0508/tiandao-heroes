# 美術方向候選 v0.3

本次原創AI圖集由image_gen依文字規格產生，未輸入原作或附件圖片；原檔fortress-atlas.png保持不變，runtime依4×4格切分。圖集1254×1254 RGBA，未假稱逐格人工像素繪製，屬pixel-inspired美術候選，尚未通過使用者正式美術驗收。

src/data/art.ts定義各格尺寸；src/data/assets.json記錄設施版本、來源與格號。舊版PNG及重製腳本保留可回溯。人物暫共用新樣本造型加色調區別，八位獨立造型與動畫仍待製作，UI人物列表暫保留原小圖。

改進：各設施獨立輪廓、瓦屋細節、燈籠、木構與院落；自然樹叢、岩石、草花點綴；修正同高度格底部假岩壁。地形邏輯與存檔不變。裝飾不具額外碰撞，不影響派工與建設合法性。

已知限制：地面仍沿用程序地塊，與細緻建築有風格差距；圖集邊界及透明邊緣須持續檢查；共享人物造型只是過渡。下一輪依使用者回饋調整尺寸、光影、色彩與細節密度。
