# 青嶺寨場景構圖 v2

針對「場景像散放建築、外圍山石零散、主要視野平坦」的試玩回饋，重做據點地形與場景配置。

## 空間層次
- 上層：4層高度的聚義高台，聚義堂與酒館形成主景。
- 中層：2層的東側市場／農田台地；1層的居住坡地、軍營與練兵場。
- 下層：0層河谷開墾地，保留玩家施工區。
- 外圍：不規則馬蹄形山脊與林坡，主要視野附近高峰8–10層以上，不再把山只放在地圖邊界。
- 逐階道路連接主寨與谷地，河流沿東側山腳蜿蜒，橋梁落在實際河面。

高度為地圖資料，建造需同高、尋路限制相鄰高差不超過1層，山岩不能通行。高台正面具有真正的陡壁，人物必須繞道坡道。保留64×64格與每層16px。

## 存檔相容
新局mapVersion=2。舊存檔沒有mapVersion時，繼續使用原地圖v1，不把已蓋設施移入新山壁。讀檔時重新繪製地形與裝飾；新舊地圖都能保存。未知地圖版本拒讀，不覆寫舊檔。要體驗新構圖，重新開頁後選「進入青嶺寨」，不讀取舊進度。

## 驗證
測試實際高台／山峰／谷地高度、所有初始設施同高與可派工、坡道每步高差、舊存檔地圖不變與新存檔重建。美術景物屬候選，非正式風格定稿。

## 山體素材
mountain-atlas.png為image_gen文字生成的原創2×2透明候選圖集，未輸入原作或附件圖像。包含連續山脊、自然岩壁、林坡與石階；由MOUNTAIN_SCENERY設定錨點，runtime切分，保留原圖。這些景物加強外圍山勢與坡道辨識，地圖高度與通行仍以qinglingTile資料為準，不能透過裝飾改變碰撞。

自然山體改用共享角點高度的連續面，不沿每格繪製垂直台階；人工建築台地仍保留擋土立面。固定鏡頭聚焦高台與居住坡道，縮放範圍不變。大型山景錨點與少量前景植被構成前／中／後景；尚需後續微調素材邊緣、地面細節及遮擋。新版新增的山體素材約數MB，首次載入量增加。
