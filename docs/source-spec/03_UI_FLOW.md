# UI / UX 流程

## 核心原則
主畫面 80% 以上是地圖。
禁止常駐大型左側管理選單。

## 主畫面
上方僅保留：
- 金錢
- 糧食
- 木材／石材
- 人口
- 稅率
- 日期
- 暫停／1x／2x／3x

## 英雄操作
直接點地圖上的英雄：
→ 浮出小型人物面板
→ 命令：建設／整地／訓練／巡邏／探索／移動／休息／詳情

## 批次操作
人物一覽 → 多選英雄 → 選擇任務 → 點選目標地區。

## 建築操作
點地圖上的設施 → 浮出小型資訊窗：
- 等級
- 規模
- 管理者
- 工作人口
- 今日產出
- 升級
- 更換管理者

## 空地操作
點空地 → 顯示可建設項目。
如果地形不符 → 顯示需要先整地／伐木／排水。

## 鏡頭
必須支援縮放：
- 100%：人物操作
- 75%：一般經營
- 50%：據點概覽
- 35%：大型府城全景
