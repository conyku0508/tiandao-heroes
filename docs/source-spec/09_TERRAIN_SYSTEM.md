# 地形與整地系統

## 地形類型
- plain 平地
- forest 森林
- hill 丘陵
- mountain 山地
- river 河流
- lake 湖泊
- coast 海岸
- sea 海洋
- marsh 濕地
- rock 岩地
- road 道路

## 地區差異
每個據點必須由 terrain seed / map file 定義不同地勢。
禁止所有城鎮只是同一張地圖換名字。

## 建築適性
一般：市場、酒館、民居 → 平地
農田 → 平地／肥沃地
漁港 → 海岸／湖岸
碼頭 → 河岸／湖岸／海岸
水車 → 河流旁
礦場 → 山地／岩地
馬場 → 草地／丘陵
林場 → 森林

## 整地
森林 → 伐木 → 平地
濕地 → 排水 → 平地／農地
部分丘陵 → 整地 → 可建築平地
山地不可任意全部削平。

## 整地成本
- 指派英雄
- 工期
- 體力
- 金錢
- 可能產出木材／石材
