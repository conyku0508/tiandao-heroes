# 《天導108星 H5 精神續作》專案總覽

## 1. 專案定位
本專案為受 1990 年代 PC 戰略經營遊戲啟發的 H5 單機策略經營遊戲原型。

核心不是直接複製既有遊戲，而是保留以下精神：
- 半即時制世界運行
- 英雄人物直接存在於據點地圖中
- 人物可被點選並執行建設、訓練、探索、移動等任務
- 據點由人口、設施、地形、資源與人物共同成長
- 玩家可隨時暫停並配置命令
- 各據點有不同地形、規模與可開發空間

## 2. 最重要的產品原則
1. **地圖本身就是主要 UI。**
2. **英雄人物就是主要操作單位。**
3. **普通居民不顯示成可操作小人，而是轉化成住宅、人口、勞動力、徵兵能力。**
4. **設施不是單純菜單數值，而是實際存在於地圖。**
5. **玩家能看見據點從荒地逐步繁榮。**
6. **半即時運作，支援暫停、1x、2x、3x。**
7. **資料／UI／程式三層分離，禁止互相硬綁。**

## 3. 技術定位
建議：
- TypeScript
- Phaser 3 或 PixiJS：等角地圖、人物 Sprite、動畫、Tile
- Vue 3：人物面板、浮動視窗、設定、資料頁
- JSON：人物、建築、地圖、事件、物品、技能
- IndexedDB：存檔
- GitHub Pages / Cloudflare Pages：測試發布

## 4. 開發流程
M0：視覺／操作原型
M1：Tile 地圖＋縮放＋鏡頭
M2：人物移動＋即時時間
M3：建築＋人口＋民宅
M4：資源與設施經營
M5：世界地圖與跨區移動
M6：簡易戰鬥
M7：內容擴充與平衡

## 5. 著作權原則
- 不使用原作圖像、UI、美術、音樂、程式碼。
- 不直接複製原作介面配置。
- 使用古典文學題材時，人物設定與視覺重新創作。
- 系統設計可參考同類策略經營遊戲的一般玩法，但需形成自身差異。
