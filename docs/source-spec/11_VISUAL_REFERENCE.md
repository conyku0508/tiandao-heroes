# 視覺與操作基準

## 目標
不是做現代手遊 City Builder。

## 正確方向
- 等角 2D／Pixel-inspired
- 建築偏小
- 地圖密度高
- 一個畫面能看到大量可開發空間
- 英雄 Sprite 清楚可辨識
- 民宅比主要設施更小
- UI 浮動、輕量，不遮住大部分地圖

## 鏡頭
預設偏遠景，強調整個據點。

## 地圖生命感
普通居民不顯示成一堆 NPC。
繁榮透過：
- 民宅數量增加
- 建築密度
- 市場攤位
- 燈火
- 煙囪
- 農田成熟度
- 港口船隻
表現。

## 人物
英雄是地圖唯一主要可操作人型單位。

## 水上移動
角色進入可通航水域後切成船隻 Sprite，靠岸後恢復人物。

## 版權
所有角色肖像、Sprite、UI、建築重新創作。
