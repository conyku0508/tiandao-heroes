# 核心遊戲循環

## 核心循環
流浪／探索 → 招募英雄 → 選擇據點 → 舉兵 → 開發地形 → 建設設施 → 人口增加 → 民宅自動生成 → 經濟與兵力成長 → 攻擊／佔領新據點 → 擴張。

## 玩家每分鐘正在做的事
- 點選英雄並派遣工作
- 暫停遊戲查看局勢
- 調整稅率
- 選擇哪片土地要整地
- 決定蓋什麼設施
- 判斷人口與住宅是否足夠
- 指派英雄管理或施工
- 觀察附近勢力與人物移動

## 中期循環
人口成長 → 住宅增加 → 生產規模增加 → 稅收增加 → 設施升級 → 更多英雄可被養活 → 軍事擴張。

## 風險循環
高稅／缺糧／拆太多民宅 → 滿意度下降 → 人口下滑 → 生產規模下降 → 徵兵速度下降 → 據點防衛變弱。
