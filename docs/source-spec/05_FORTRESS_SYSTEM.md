# 據點／山寨系統

## 據點不是固定大小
每個據點有自己的地圖尺寸與可開發容量。

建議初始級別：
- 小村／小寨：20–30 個主要設施容量
- 城鎮：30–40
- 中型城市：40–50
- 大型府城：45–60

注意：設施容量 ≠ Tile 數量。整張地圖仍可有 150–300+ Tile。

## 同類設施可重複
不限制市場只能幾個、酒館只能幾個。
真正限制：
- 土地
- 地形
- 人口
- 資源
- 管理能力

## 建築三級制
每一個建築 Instance 都可 Lv1 → Lv2 → Lv3。

## 建築規模與等級分離
- 等級：玩家投資升級的硬上限
- 規模：人口與經營狀況造成的動態數值

例如：酒館 Lv2，最大規模 120，目前 68。

## 建築比例
建築視覺須小型化。
目標：一個一般視野能同時看到 20–40 個設施／住宅單位，大型府城縮放後可看到 50+。
