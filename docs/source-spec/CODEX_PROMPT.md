# CODEX 開發總提示詞

你正在開發一款 H5 單機策略經營遊戲 Prototype。

## 絕對規則
1. 資料、UI、程式三層完全分離。
2. 不使用任何原作美術、音樂、UI 或程式碼。
3. 主畫面是等角據點沙盤，不做大型常駐左側 Dashboard。
4. 地圖上只顯示英雄／重要人物；普通居民以人口數值與自動生成民宅呈現。
5. 遊戲採半即時制：Pause / 1x / 2x / 3x。
6. 人物下令後會實際走到目標執行任務。
7. 同類設施可以重複興建。
8. 建築可 Lv1–Lv3，且另有動態「規模值」。
9. 民宅會隨人口自動生成並占地；拆除住宅會影響人口容量。
10. 人口影響設施規模、勞動力與軍營徵兵速度。
11. 不同據點擁有不同地形與可開發容量。
12. 地形限制建築；森林等地形可以透過整地改造。
13. 人物跨越可通航水域時自動切換成小船 Sprite，靠岸恢復人物。
14. 地圖與建築比例偏小，需支援高密度據點與縮放。

## 開發順序
不要一次完成整款遊戲。

### M0
只做視覺與互動 Prototype：
- 1 張完整據點地圖
- 8 名英雄
- 點選人物浮出命令框
- Pause / 1x / 2x / 3x
- 縮放

### M1
加入英雄移動與任務。

### M2
加入地形與建築。

### M3
加入人口、民宅自動生成、稅率與設施規模。

### M4
加入世界地圖、據點差異與水上移動。

每完成一階段先提交可玩 Demo、截圖與 CHANGELOG，不要擅自進入下一階段。
