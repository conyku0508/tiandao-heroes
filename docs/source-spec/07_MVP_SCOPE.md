# MVP 範圍

## 目標
第一版只驗證「這個玩法好不好玩」。

## MVP 據點
1 個完整可玩據點 + 3–5 個世界地圖節點。

## MVP 英雄
8–12 人。

## MVP 設施
- 民宅（自動生成）
- 農田
- 市場
- 酒館
- 糧倉
- 演武場
- 軍營
- 鐵匠鋪
- 碼頭／漁港

## MVP 地形
- 平地
- 森林
- 山地
- 河流
- 海／湖
- 道路

## MVP 時間
- 暫停
- 1x
- 2x
- 3x

## MVP 必須驗證
1. 英雄可以點選與移動
2. 英雄可執行工作
3. 時間會推進
4. 民宅會依人口自動生成
5. 拆民宅會減少人口／容量
6. 人口影響設施規模與徵兵
7. 地形限制建築
8. 森林可以整地成平地
9. 河流移動自動變成小船
10. 建築可重複興建與升級
