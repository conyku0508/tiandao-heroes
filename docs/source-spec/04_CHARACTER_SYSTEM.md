# 英雄人物系統

## 角色定位
地圖上會直接出現的是「英雄／重要人物」，不是一般居民。

## 基礎能力
- 武力
- 技能
- 智力
- 魅力
- 體力
- 忠誠
- 仁愛
- 勇氣

## 工作適性
- 建設
- 農業
- 商業
- 軍事
- 工匠
- 航海
- 探索
- 外交

## 地圖行為
英雄具有：
- 位置
- 移動路徑
- 任務
- 工作動畫
- 體力消耗

## 直接操作
點人 → 下命令 → 人物走到目標 → 開始執行。

## 批次操作
支援多人同時：
- 整地
- 建設
- 訓練
- 探索
- 護送

## 過河
英雄路徑進入可通航水域時：
- 若有橋，優先走橋。
- 無橋但可通航，角色自動切換「小船 Sprite」。
- 到岸後恢復人物 Sprite。
- 航海適性影響速度。
