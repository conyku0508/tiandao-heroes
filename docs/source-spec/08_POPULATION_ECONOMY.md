# 人口與經濟核心系統

## 核心概念
普通居民不是地圖角色，而是人口數值與自動生成住宅。

## 人口拆分
- totalPopulation：總人口
- housingCapacity：住宅容量
- laborPopulation：勞動人口
- recruitablePopulation：可徵兵人口

## 民宅自動生成
當：
- 稅率合理
- 糧食足夠
- 滿意度高
- 有可用土地
人口會成長，系統會自動在合適 Tile 產生民宅。

## 民宅選址偏好
1. 平地
2. 道路附近
3. 市場／酒館附近
4. 工作設施附近
5. 山地可產生少量山屋型住宅

## 拆除民宅
拆除住宅後：
- housingCapacity 下降
- 若容量不足，人口逐步外流
- 滿意度可能下降
- 勞動人口與可徵兵人口跟著下降

## 人口影響
人口越高：
- 市場／酒館／農田等設施規模成長更快
- 稅收增加
- 軍營徵兵速度增加
- 城市繁榮視覺提高

## 稅率
低稅：人口成長快、短期收入低
中稅：平衡
高稅：收入高、滿意度下降、人口可能萎縮

## 設施規模
設施規模受：
- 人口
- 滿意度
- 糧食
- 管理者
- 建築等級
- 周邊環境
影響。
