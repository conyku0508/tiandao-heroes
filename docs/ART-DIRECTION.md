# Task2美術製作規範草案（尚未驗收）

精緻16-bit古風像素、固定45度平面方向及2:1菱形格64×32，階高16px暫定。民宅小於主要設施；一般視野20–40單位、大城遠景50+，保持英雄辨識度與地圖80%目標。山林、河流、平原、道路、坡道、岩壁與橋互相連通，地形與通行／建設資料一致。

建議色系：青黛瓦、赭土、松綠、稻金、河青；左上光源，右下陰影，禁止平滑放大與材質光源混亂。資產底部接地錨點，依地塊與高度排序，遮擋與點選範圍獨立。英雄以衣色和輪廓辨別，不靠覆蓋大名牌。

assets.json已列11項獨立資產ID，皆planned，無圖片。後續每項記版本、作者／工具、原創來源、授權、尺寸、footprint、anchor、碰撞、遮擋與動畫影格；舊版糧倉、鐵匠鋪、碼頭、林場等保留待擴充。

附件與訊息參考圖僅供比例／密度討論，不裁切、不描摹、不直接包入遊戲。Task1空白引擎畫布只是啟動診斷，不是臨時地圖，也不代表美術完成。Task2須交地形／建築圖集、完整地圖、手機與桌面截圖，待使用者確認方向。
